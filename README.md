# 💖 Jaan — A Memory & Apology Website

> "Some memories deserve more than words. They deserve a place where they can live forever."

A beautiful love-themed interactive website created as a heartfelt apology and memory album for someone truly special.

This project combines beautiful UI, smooth animations, heartfelt messages, music, videos, and precious memories into one immersive experience.

---

## ✨ Features

- 🌸 Beautiful pink, lavender & purple aesthetic
- 💌 Heartfelt handwritten apology letter
- 📸 Memory gallery with 30+ photos
- 🎞️ Timeline of unforgettable moments
- 🎥 Personal video memories
- 🎵 Background music player
- ✨ Smooth scroll & reveal animations
- ❤️ Floating hearts and romantic effects
- 📱 Fully responsive design
- 💖 Cute ending with a forgiveness screen

## 🚀 How to Run

Clone the repository

```bash
git clone https://github.com/akshithasriram07/jaan.git
```

Open the project folder

```bash
cd jaan
```

Run `index.html` using Live Server or open it directly in your browser.
